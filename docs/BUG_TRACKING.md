| Level | Description | Response |
|-------|-----------|----------|

| P1 | Major feature broken, blocks user flow | Fix within 24h |
| P2 | Minor feature issue, workaround exists | Fix within sprint |
| P3 | Cosmetic, low impact | Backlog |
