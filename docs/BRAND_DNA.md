# BrinMetal -- Brand DNA

## Brand Identity

BrinMetal is an engineering brand. Not a trades brand. Not a services brand. An engineering brand that happens to work with metal.

## Brand Personality

| Trait | Expression |
|-------|-----------|
| Authoritative | Speaks with confidence, never oversells |
| Precise | Every detail matters, nothing is approximate |
| Powerful | Communicates capability and strength |
| Trustworthy | Proven track record, transparent approach |
| Premium | Quality in every touchpoint |

## Brand Voice

- **Tone:** Confident, direct, professional
- **Language:** Technical but accessible. Never dumbed down, never jargon-heavy
- **Style:** Short, impactful statements. No fluff. No filler
- **Avoid:** Exclamation marks, hype words, startup language, casual tone

### Voice Examples

Good: "20 years of structural precision."
Bad: "We're passionate about welding!"

Good: "Engineered for permanent installation."
Bad: "Built to last forever!!!"

Good: "Custom fabrication. Exact specifications."
Bad: "We can make anything you dream of!"

| Gunmetal | #2a2d35 | Card backgrounds, elevated surfaces |
| Dark Steel | #353840 | Subtle borders, dividers |
| Titanium | #8a8d93 | Secondary text, subtle elements |
| Warm Steel | #b0a999 | Accent borders, decorative elements |

### Functional Colors

| Name | Hex | Usage |
|------|-----|-------|
| Copper Hover | #d4a57a | Hover state for copper elements |
| Copper Muted | #c4956a33 | Copper at 20% opacity for backgrounds |
| Error | #e54545 | Form validation errors |
| Success | #4a9e6a | Success states |

### Color Rules

1. Background layers: graphite (base) > gunmetal (cards) > dark-steel (elevated)
2. Copper is used sparingly -- CTAs, key highlights, accent lines only
3. Never use pure black (#000000) or pure white (#ffffff)
4. Text hierarchy: off-white (headings) > titanium (body) > warm-steel (subtle)
5. Minimum contrast ratio: 4.5:1 for body text, 3:1 for large text

## Typography Strategy

### Heading Font
**Recommended:** A geometric, extended typeface with industrial character.
Options to evaluate:
- Monument Extended (if licensed)
- Space Grotesk (open source, geometric)
- Outfit (open source, clean industrial)

Requirements: Strong at large sizes, geometric, architectural feel, supports Latin characters.

### Body Font
**Recommended:** Clean, highly readable sans-serif.
Options to evaluate:
- Inter (open source, excellent readability)
- Satoshi (modern, clean)

Requirements: Excellent readability at small sizes, clean rendering, multi-language support.

### Hebrew Font
Must pair well with the Latin heading font. Options:
- Heebo (clean, modern Hebrew)
- Rubik (geometric Hebrew)
- Assistant (neutral Hebrew)

### Russian Font
Inter and most recommended body fonts support Cyrillic natively.

### Type Scale

| Level | Size (desktop) | Weight | Line Height | Usage |
|-------|---------------|--------|-------------|-------|
| Display | 72-96px | 800 | 1.0 | Hero headlines |
| H1 | 48-64px | 700 | 1.1 | Page titles |
| H2 | 36-48px | 700 | 1.15 | Section titles |
| H3 | 24-32px | 600 | 1.2 | Sub-sections |
| H4 | 20-24px | 600 | 1.3 | Card titles |
| Body Large | 18-20px | 400 | 1.6 | Lead paragraphs |
| Body | 16px | 400 | 1.6 | Default body |
| Body Small | 14px | 400 | 1.5 | Captions, meta |
| Label | 12-14px | 500 | 1.4 | Buttons, labels |

### Typography Rules

1. Headings use the display/heading font exclusively
2. Body text uses the body font exclusively
3. All caps for labels, navigation, and small UI elements -- with letter-spacing: 0.05-0.1em
4. No italic except for rare emphasis in body text
5. Font smoothing: antialiased on dark backgrounds

## Logo

Text-based logo: "BrinMetal" or "BRINMETAL"
- Clean, geometric typeface
- No icons or symbols in the primary logo
- Works at all sizes
- Monochrome -- off-white on dark backgrounds

## Photography Direction

- Cinematic lighting (dramatic, directional)
- Architectural composition
- Close-up detail of metalwork quality
- Workshop environment shots (controlled, not messy)
- Finished project photography (in-situ, professional)
- No stock photography
- No posed portraits
- Color grading: desaturated, warm shadows, cool highlights
